
# Loan Management System

A full-stack loan management application built with React and Django to help manage customers, loan records, and user access through a web-based interface.

## 🚀 Features

### ✅ Implemented
- **Customer Management:** Manage customer records.
- **Loan Management:** Manage loan records and related information.
- **User Authentication:** Login functionality for accessing the application.
- **Frontend–Backend Integration:** React communicates with the Django backend through API endpoints.

### 🚧 In Development
- Repayment management
- Reports and analytics

## 🛠️ Tech Stack

### Frontend
- React
- JavaScript
- Axios for API communication, if used in the current implementation

### Backend
- Python
- Django
- Django REST Framework, if used in the current implementation

### Database
- The database configured for the Django application

## 🏗️ Application Structure

The application separates the frontend interface from the backend API.

- **React frontend:** Provides the user interface for customer and loan management.
- **Django backend:** Handles application logic and data management.
- **API integration:** Allows the frontend to communicate with the backend.

## ⚙️ Getting Started

### Prerequisites
- Python
- Node.js and npm
- A database supported by the project's Django configuration

### Backend Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/codera001/Loan-Management-System.git
   ```

2. Navigate to the backend directory:

   ```bash
   cd Loan-Management-System
   ```

3. Create and activate a Python virtual environment.

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

4. Install the backend dependencies using the project's requirements file.

   ```bash
   pip install -r requirements.txt
   ```

5. Apply database migrations:

   ```bash
   python manage.py migrate
   ```

6. Start the Django development server:

   ```bash
   python manage.py runserver
   ```

### Frontend Setup

Open a separate terminal and navigate to the frontend directory.

```bash
cd LMS-frontend
npm install
npm run dev
```

Use the frontend start command specified in the project's `package.json` if it differs from `npm start`.
